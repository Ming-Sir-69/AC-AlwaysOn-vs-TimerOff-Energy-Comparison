# 空调常开还是定时关更省电？

用于比较“持续恒温”和“外出关机、返回重启”两种策略的热力学仿真研究，结合牛顿冷却定律、田口正交设计与 ANOVA。适合学习实验设计、模型假设与可视化表达的读者。

## 从哪里开始

- 先看 [数学公式与来源](docs/07_公式汇总与来源索引.md) 和 [开发说明](README_DEV.md)，理解模型假设与参数空间。
- 浏览 [交互仪表盘 HTML](interactive/能耗对比交互仪表盘.html)、[图表](outputs/charts/)、[Excel 结果](空调能耗仿真结果.xlsx) 或 [综合报告](空调能耗对比研究_综合分析报告.pptx)。HTML 可下载后在浏览器查看；当前文件树中的仪表盘是 HTML 文件。
- 要研究实现，从 [主入口](src/run_simulation.py)、[全局配置](src/config.py) 与 [热力学模型](src/thermal_model.py) 开始。

在下载或克隆的仓库副本中准备 Python 与 pip，按既有开发文档执行：

```sh
cd src
python3 -m pip install -r requirements.txt
python3 run_simulation.py
```

## 工作流

1. **理论建模** — 牛顿冷却定律 + COP衰减 + 14条公式推导
2. **田口正交实验** — L25/L50正交表 + 5因子参数空间扫描
3. **仿真引擎** — Python热力学仿真 + 双方案能耗对比
4. **多维可视化** — 30+张分析图表（3D曲面/热力图/敏感性分析）
5. **综合报告** — PPT + Excel + 交互仪表盘 + 学术版

## 核心结论

- **外出时长是唯一显著因子**（Beta=0.848，解释84.8%方差）
- **28°C 是热惯性激活阈值** — 低于此温度建筑自身保温已足够
- **高温长时场景(>34°C, >8h)关空调可节能 45-55%**
- **短暂外出(<30分钟)不应关机** — 重启能耗大于维持能耗
