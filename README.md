# 宿舍空调：提前预冷、休息日供电与定时强制断电的能耗和室内热湿对比

本项目比较一间华南厂区四人宿舍的两种供电规则。现行规定在工作时段整间断电，休息日也按工作日时间执行，来电后空调需人到场手动开启；对照方案在工作日按上下班时间提前开机预冷，休息日不按工作日时间断电。项目采用三节点热网络加湿度节点的逐分钟模型，在 128 组配对参数情景下计算一个制冷季（184 天）的空调电量与室内温湿度。

## 主要结果

**两种规则的电量差主要来自休息日：工作日每天只多约 0.1 kWh，休息日每天多约 1.3 kWh；换来的是到家时和休息日在室时的室温明显下降。**

- 整季电量：预冷与休息日供电比现行规定多用 **82 kWh**（51–160，定频）；变频为 62 kWh（37–117）。
- 下班到家时室温：**85°F → 80°F**（29.4°C → 26.6°C）；降到 28°C 以下的中位时间由 29 分钟缩短到 4 分钟。
- 休息日在室时段的季内最高室温：**91°F → 83°F**（32.9°C → 28.2°C）。
- 在室热暴露（超过 28°C 的幅度乘时长）减少 449 °C·h（47–1253）。

统计口径：中位数（5–95% 情景范围），定频机组；情景为西向 ±30°、二层非顶层、单面外墙的 128 组配对参数样本，各规则共用人员日历与气象。预冷提前量基准 30 分钟，情景范围 10–60 分钟。区间反映参数不确定性，不是置信区间。

## 研究对象

房间净尺寸为 3.70×6.20×2.80 米，两端各为 2.10 米的桌柜与高架床单元，中段为 2.00 米落地床。两张高架床、两张落地床、四张 L 形桌和四只双门柜构成四人的蓄热体与在室热源；两扇磨砂窗与阳台门上半部合计 1.90 ㎡ 净玻璃，门下半部深色铝合金板及门窗框作为独立的不透明传热支路。

## 方法

- 几何与构件：按上节的尺寸、家具与门窗建模，阳台朝西（270° ±30°）。
- 热湿模型：空气、内墙家具蓄热、外墙屋顶三个热节点，加空气含湿量和盘管存水；外表面热平衡参照 EnergyPlus 工程参考<sup>[[1]](#参考文献)</sup>，湿空气性质计算参照<sup>[[3]](#参考文献)[[10]](#参考文献)[[11]](#参考文献)</sup>；一分钟积分，逐时气象驱动<sup>[[4]](#参考文献)[[5]](#参考文献)</sup>，太阳位置按 NOAA 算法<sup>[[8]](#参考文献)</sup>。
- 现行规定：每天（含休息日）四段断电，08:00–10:30、10:40–12:00、13:30–15:00、15:10–17:30；来电后空调需手动开启，工作日两次 10 分钟供电时无人在室。
- 对照方案：工作日在午休返回和下班到家前提前开机预冷，08:00、13:30 离开时关机，两次短时来电不开机；休息日全天供电，在室时开机。
- 机组：定频与变频两类，含最短开停机时间、部分负荷效率与盘管除湿<sup>[[2]](#参考文献)</sup>。
- 围护结构表面换热与涂层太阳吸收率的取值范围参照 ASHRAE 手册与 EPA AP-42<sup>[[6]](#参考文献)[[7]](#参考文献)</sup>；参数取值、来源与假设范围见 [模型与来源](模型与来源.md)。
- 敏感性：Sobol 全局敏感性分析，Saltelli 抽样与 SALib 估计<sup>[[12]](#参考文献)[[13]](#参考文献)</sup>。

## 局限

- 模型未经现场电量与温湿度实测校准，也未与 EnergyPlus 等工具对算；结果适用于所设边界条件。
- 换气率、楼层位置（按非顶层处理）和机组性能曲线为假设。敏感性分析中，电量增量对换气最敏感，其次为额定能效、墙体传热和预冷提前量。
- 顶层或转角房间的电量差显著更大，见“详细数据”中的对照表。

- 定频：现行规定相对一直开节电 17.4（10.5–23.3）%；改成预冷+休息日供电，整季相对现行规定多用 82（51–160） kWh。
- 变频：现行规定相对一直开节电 16.4（10.5–21.2）%；改成预冷+休息日供电，整季相对现行规定多用 62（37–117） kWh。

**工作日两次10分钟供电时无人，空调不会自己开，因此没有空调制冷恢复。** 现行规定在午休和下班返回后手动开；预冷方案按返回日历提前定时开机。提前供电且仍手动是另一条规则，不等于预冷。

<details>
<summary><b>已确认与仍在假设的条件</b></summary>

- 实际四人间、住4人。家具是两张高架床、两张落地床、四张L形桌、四只双门铁柜。房间工作尺寸约3.7×6.2×2.8米，依据过道横向三块砖加两排家具、家具占满长墙及口述，仍非实测；净宽3.6–4.4、净长6.0–6.4、净高2.6–3.2米作为情景范围。床长约占3.3格，场景判读地砖更可能0.6米，把握中低，仍未实测。0.8米砖的4.3×6.2米及口述上限4.8×6.2米另列对照。

<details>
<summary><b>哪些条件更影响结果</b></summary>

仅针对深圳站一个炎热周、主房间及规定时段，以512对基础样本和27个输入做全局敏感性分析；不代表整季名次。该扫描固定非顶层、单面外墙，方位限制为西向±30°，不再把顶层/转角当未知开关。指数大小仍依赖27个未定输入的所选范围。输出为预冷方案减现行的用电增量、现行减预冷的在室热暴露。输入含预冷提前量、返回和手动反应延迟，已知人数不再抽样。总效应包含交互，不加总成百分比，区间是配对重采样95%范围。

- 定频预冷用电增量：换气 0.43（0.38–0.51）、额定能效 0.26（0.22–0.30）、墙体传热 0.05（0.05–0.06）。
- 定频减少的热暴露：建筑内蓄热 0.49（0.41–0.57）、设定温度 0.19（0.17–0.22）、制冷能力 0.13（0.10–0.17）。
- 变频预冷用电增量：换气 0.49（0.41–0.58）、制冷能力 0.16（0.13–0.21）、额定能效 0.15（0.13–0.18）。
- 变频减少的热暴露：建筑内蓄热 0.45（0.37–0.53）、设定温度 0.19（0.17–0.23）、制冷能力 0.13（0.10–0.16）。
- 定频预冷提前量10–60分钟：用电增量 总效应 0.048（0.040–0.056）；减少热暴露 总效应 0.001（0.001–0.002）。
- 变频预冷提前量10–60分钟：用电增量 总效应 0.029（0.024–0.034）；减少热暴露 总效应 0.001（0.001–0.002）。

区间重叠时不强调精确排名。主相图固定四人、相同门窗与机组，按固定断电与手动行为扫描面积及墙体传热；不以单段时长替代规定。

</details>

<details>
<summary><b>方法、核对与局限</b></summary>

- 空气、内墙家具蓄热体、外墙屋顶合并节点，共三个热节点；另有空气含湿量和盘管存水状态。一分钟积分，逐时气象驱动，人员与设备热源随在室和供电变化。
- 定频最短开机基准300秒、核对范围180–600秒，最短停机180秒、核对范围120–300秒；另做两站整季3×3时间组合扫描。这两项未加入原全局抽样，启动次数是计时器与控制假设的产物，不能当作实机预测；启动爬升基准45秒、范围15–90秒。变频有部分负荷效率和容量约束；两类曲线是假设，未有厂家校准。电量按实际可用容量和效率计算，未把空气侧上限再算成额外损耗。
- 除湿按进风温湿度、有效盘管露点、风量与旁通比例动态分配显潜热，记录盘管存水、排水和停机回蒸；另扫盘管温度/风量/存水量。盘管露点在每条轨迹内固定（基准12°C），不随变频转速改变，可能高估低速除湿。仍没有独立湿控、材料吸湿、湿盘管完整厂家曲线或床位空间差异，不能保证主观不闷。
- 内置热水余额只是离散自检。`audit.py`在一个炎热周内、无预热且初态已知时，另从输入气象与保存状态做热、水后处理记账；冷量与运行比例仍读自模拟输出，电量是按同一功率公式重算。篡改输出的测试能检出部分差错，但没有独立求解控制与盘管，也不是整季或实测验证。证据见 `results/west_independent_budgets.csv`。
- 一节点指数解、三节点矩阵指数解、湿量混合解析解及步长/预热/收尾/气象替换检查均有记录。五分钟显式步长在紧凑主房间不稳定，已拒绝，不列作物理结果；主结果用一分钟。**没有运行EnergyPlus对算，没有现场温湿度与电量验证。** 两周电费较低的回忆最多说方向一致。
- 外墙有效蓄热只相当于约36毫米混凝土，并非实际墙厚；屋面与墙共用U值和一个节点，可能夸大顶层高温，尤其高温尾部，不能把高温尾部当现场预测。无阳台挑檐遮阳，人体显热/潜热各为常数、不随室温调整。相邻房间热交换、门窗实际开合、天空长波、风扇体感未模拟；风机热未单独反馈室内。门窗默认关闭，换气是假设。若阳台门经常开着，需另算换气工况。
- 参数范围、来源、固定与派生方式见 `data/confirmed_parameters.csv`；详见 [模型与来源](模型与来源.md)。家具材料质量尚未核实，不能拿场景概念图当作精确热模型或气流仿真。

</details>

<details>
<summary><b>复现与待核实资料</b></summary>

逐分钟曲线以无损压缩的 `.csv.gz` 保存，读取后的数值不变。公开包保留定稿房间的完整汇总结果与西向逐分钟轨迹；广朝向的逐分钟轨迹可选生成，不随包提供。如需生成广朝向轨迹，运行 `uv run --frozen python run.py --traces-only`。

在本目录运行，需Python 3.12与uv，按锁文件安装依赖；原始气象和哈希已保存。

```sh
uv run --frozen python -m pytest -q
uv run --frozen python run_confirmed.py
uv run --frozen python verify_confirmed.py
uv run --frozen python render_figures.py --report
```

场景重建需要Blender 4.2 LTS，已用4.2.23验证。运行 `blender --background --factory-startup --python scene/source/build_model.py` 可生成场景；五个视角的渲染和JPG压缩命令见 [场景说明](scene/README.md)。场景图不参与热计算。

只更新图表、不运行仿真时，可运行 `uv run --frozen python render_figures.py --report`。图表需系统苹方SC、Noto Sans SC或思源黑体之一；图件使用苹方SC，导出的SVG已转曲，阅读图件不依赖字体安装。

默认128个共用参数样本。西向主基准三种房间×两类机组×八条规则，共6144条整季轨迹；朝东/顶层/转角各在主房间计算一直开、现行、自主开关和预冷方案，共3072条对照，总计9216条。Sobol基础样本512对、27个输入。随机种子固定，执行测试、数据、八张核心图及四张补充图和本文生成；每张有亮暗、宽窄四版PNG与SVG。

二楼、非转角、阳台朝西已经确认；总层数未知，非顶层仍是明确假设。方位精度、净尺寸与层高、玻璃面积、门窗开合、机组曲线和返回延迟仍非实测，是结果的未解决局限；将来有实测温湿度和分项电量后才能进一步校准。

</details>
